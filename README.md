## 📋 Programming Survey Form

A simple and user-friendly Programming Survey Form developed using HTML5 and CSS3. This project collects user information, professional roles, programming skills, and feedback through text fields, dropdown menus, radio buttons, checkboxes, and a comments section. It features a clean layout, custom colors, spacing, and box-shadow effects to enhance the user experience.

### 🛠️ Technologies Used
- HTML5
- CSS3

### ✨ Features
- Personal information input fields
- Role selection dropdown
- Recommendation survey with radio buttons
- Programming languages and frameworks selection
- Comments and suggestions section
- Custom styling and user-friendly design

### 🚀 How to Run
1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Fill out the survey form and explore its features.

### 🎯 Project Objective
To practice HTML form elements, input controls, and CSS styling while building a basic web interface.
